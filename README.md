# 📊 Olist E-commerce Business Intelligence Tool

## 📝 Project Overview
This project provides a comprehensive data analysis and a Strategic BI Dashboard for **Olist**, the largest department store in Brazilian marketplaces. The goal is to analyze **100,000+ orders** from 2016 to 2018 to improve operational decision-making, optimize sales, and enhance customer satisfaction.

## 🚀 Key Business Insights & Strategy
Beyond the charts, this project proposes a **Demand Shifting Strategy**:
* **The Problem:** Heavy sales spikes in **Q4** (Peak Season) leading to logistics bottlenecks and lower review scores.
* **The Solution:** Implementing an **"Early Bird" campaign** one month before the peak to balance the workload.
* **Revenue Optimization:** Applying **Premium Pricing** during peak days to maximize profit margins.

## 🛠️ Technical Stack
* **Excel (Advanced):** Used for the final presentation and interactive dashboard.
* **Power Pivot & DAX:** Created complex measures and calculated columns.
* **Power Query:** Performed ETL (Extract, Transform, Load) to clean and shape the data.
* **Data Modeling:** Designed a **Star Schema** to connect 8 relational tables efficiently.

## 🏗️ Data Architecture (Star Schema)
The project is built on a robust relational model including:
* **Fact Table:** `Orders_Items`
* **Dimension Tables:** `Customers`, `Products`, `Sellers`, `Payments`, `Geolocation`, and `Reviews`.


## 📈 Dashboard Features
* **Executive Summary:** Total Sales ($12.4M), Order Count (99k+), and Avg. Review Score (4.0).
* **Geographic Analysis:** Deep dive into sales by state (Top performer: São Paulo).
* **Payment Behavior:** Distribution of payment types (Credit Card, Boleto, etc.).
* **Seasonality Trends:** Quarterly sales growth analysis to identify peak periods.

## 📂 Project Structure
* `Data/`: Raw and cleaned datasets.
* `Dashboard/`: The final Excel (.xlsx) file with Power Pivot enabled.
* `Screenshots/`: Images of the dashboard and data model.
